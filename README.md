# Amazon Products Web Scraping

<p align="center">
Extraction automatisée de données produits Amazon avec Python & BeautifulSoup
</p>

---

## Description

Ce projet consiste à développer un système de Web Scraping permettant d’extraire automatiquement des informations produits depuis Amazon.

L’objectif est de collecter et structurer des données e-commerce afin de faciliter leur exploitation pour :
- l’analyse de données,
- la veille tarifaire,
- le reporting,
- ou la visualisation de données.

Le scraper récupère plusieurs informations telles que :
- Nom du produit
- Prix
- Note utilisateur
- Nombre d’avis
- Disponibilité
- Lien produit

Les données extraites sont ensuite stockées dans un format exploitable (CSV/JSON).
